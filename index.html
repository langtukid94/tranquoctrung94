FAQ

Câu hỏi thường gặp
Vì sao trước đây bị lỗi 404 CV?

Do link vẫn trỏ “assets/” nhưng bạn đã xóa thư mục assets. Bản này dùng đường dẫn trực tiếp: CV_Trung.pdf.

GitHub có phân biệt chữ hoa thường không?

Có. “CV_Trung.pdf” khác “cv_trung.pdf”. Phải đúng y hệt tên file.

Muốn thay ảnh/giữ đẹp thì làm sao?

Chỉ cần thay file avatar.jpg bằng ảnh mới (giữ đúng tên) rồi commit + push.

Có thể thêm nhiều trang (multi-page) không?

Được. Nhưng hiện tại bạn yêu cầu 1 file duy nhất, nên làm kiểu “nhiều section” trong 1 trang cuộn.

Muốn form gửi tin nhắn hoạt động thật thì sao?

GitHub Pages không có backend. Bạn có thể dùng Google Form, Formspree, hoặc email mailto.

Làm sao kiểm tra nhanh đã deploy chưa?

Mở link trực tiếp: /avatar.jpg và /CV_Trung.pdf. Nếu mở được là OK.
